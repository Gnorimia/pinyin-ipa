# 知然音鉴 · 汉语工具箱

汉语拼音 → **严式国际音标（IPA）** 的在线转写工具，单文件、纯前端、离线可用。

在线使用：<https://gnorimia.github.io/pinyin-ipa/>

## 功能

- **拼音 → 严式 IPA**：输入 `ni hao` / `nǐ hǎo` / `ni3 hao3` 均可，输出带调符的严式记音，同时给出宽式对照。
- **声母、韵母、儿化**：按声母表／韵母表／儿化韵规则逐项转写，可切换老派／中派／新派。
- **声调**：五度制调符与调值，说明各派实际调值差异。
- **日语音标**：假名、平文式、训令式罗马字 → IPA，附逐拍对照（促音、拨音、长音）。
- **韩语音标**：谚文、文化观光部式、麦库恩－赖肖尔式 → IPA。
- **越南语音标**：国语字 → IPA（河内音）。
- **国际音标表**：内置中文版（2005 修订）、英文版（IPA Kiel，2015 修订）与 extIPA（2025）三张表。

## 特点

- **单文件**：HTML、CSS、JS、字体、图片全部内嵌（base64），双击即可用，不需要服务器，也可离线。
- **真字体**：音标用 Charis SIL，中文用思源宋体（子集化），日文假名用思源宋体 JP，谚文用 KR——都是完整字形，不用系统回退。
- **无依赖**：不加载任何外部 CDN 资源，不上报任何数据，输入内容只留在本地。
